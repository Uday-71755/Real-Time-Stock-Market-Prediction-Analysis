# Real-Time-Stock-Market-Prediction-Analysis

This project presents an end-to-end data engineering and machine learning pipeline designed to predict stock market trends in near real-time. Leveraging the yfinance API, historical stock data is ingested and preprocessed using Python and Pandas to engineer features such as daily returns. The cleaned data is used to train a Random Forest Regressor model, which is then serialized and deployed for inference. The system is hosted on an AWS EC2 instance and supports two modes of user interaction: a Flask-based REST API and a Streamlit dashboard. Users can upload stock parameters (Open, High, Low, Close, Volume) and receive predicted returns along with visualizations such as trend charts and feature importance. The solution addresses critical business needs in financial analysis, including real-time decision-making, risk mitigation, and algorithmic trading support. Key deployment considerations like manual resource management, security configurations, and cost monitoring on EC2 were also explored. Overall, this pipeline showcases how open-source tools and cloud infrastructure can be combined to deliver scalable and interactive financial analytics applications.
